Admin

Ktemata is managed from its own page on the device, not from a separate stack. Open http://<device>:8081/ on the hotspot or the LAN, sign in, and the library is in one place.

  • One pagestorage, library, power and AI
  • Poweron power or on battery, with runtime
  • All indexed ZIMsone question across the archives
  • Dark / lighta theme that stays with the browser

Storage & archives

The top row combines disk use with the archive count and total ZIM size. Upload a ZIM by drag and drop — transfers are chunked, resumable and checked for the ZIM magic before they are published. Delete an archive or discard an interrupted upload. A new or removed file is not served until the library index is rebuilt.

Library index

Rebuild index & restart runs kiwix-library, then restarts kiwix-serve. The index box flags an unreadable file, a missing index, an out-of-date index, or a healthy one. Archive-row states use the same language everywhere:

  • green — indexed and ready;
  • yellow — not indexed yet;
  • orange — being indexed now;
  • red — an error that needs attention.

Power

The power box reads the UPS Module 3S's INA219 gauge. It says On power or On battery, shows the pack percentage, and gives an estimated time left while discharging. The reading is cached for a few seconds so refreshing the page does not hammer the I²C bus. The details are on the power page.

AI indexes and Ask

Every ZIM can carry its own KiwixRAG vector index. The AI index column builds or rebuilds one in the background through a systemd unit, and shows the same four states as the library index. The page reports the article and chunk count when it finishes.

Ask the library has one question box and a source selector:

  • Documents searches the extracted document index;
  • a ZIM archive queries that archive's Chroma index;
  • All indexed ZIMs queries every complete index, merges the chunks by embedding distance, and answers from the best few. Sources name the archive and chunk.

The answer is local-model output, not a lookup. It can be wrong even when the retrieval is right; the source paths under the answer are the part to check.

Theme and access

The header has a dark/light theme button; the choice is stored in the browser. The admin listens on :8081 with HTTP Basic auth, but no TLS. Keep it on the hotspot or a trusted LAN, or bind it to loopback and use an SSH tunnel. The library itself is on :8080; the admin is a separate service so a broken library rebuild does not take the management page down.

The page is served by ktemata-admin.py in the repository. It needs no framework and no external service; the same CLI it calls is available over SSH for automation.

sudo ./work/scripts/post-install.sh
